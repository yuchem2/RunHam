Ready-made custom metric cards, and a Settings window that stays tidy as you add more of them.
바로 쓰는 커스텀 메트릭 카드와, 카드가 늘어도 깔끔한 설정 창.

## What's new

- **Ready-made cards** in [`scripts/`](https://github.com/yuchem2/RunHam/tree/main/scripts): Claude Code usage, Codex usage limits, GitHub (review requests, your PRs and CI), Docker, Homebrew and Kubernetes. Run one with `--watch` and add its JSON file in **Settings › Metrics**. See the [guide](https://github.com/yuchem2/RunHam/blob/main/Formats/custom-metrics.md#ready-made-cards).
- **Show on Dashboard** checkbox for each custom metric, so you can hide a card without removing it.
- The custom metrics list, the custom toggles in the Metrics Bar section and the custom runners list now show three rows and scroll, instead of making the window longer.
- Settings now opens on the **Runner** tab.

## Install / Update

**Requires macOS 14 or later on Apple silicon (M1 or later).**

1. Quit RunHam if it's running. Your settings, runners and metrics are kept.
2. Download `RunHam-0.1.1.zip` below, unzip it and move `RunHam.app` to the Applications folder (replace the old one).
3. RunHam is not notarized by Apple yet, so the first launch is blocked. Open it once in one of these ways:
   - Right-click (or Control-click) `RunHam.app` and choose **Open**, then **Open** again.
   - Or try to open it, then go to **System Settings › Privacy & Security** and click **Open Anyway**.
   - Or run `xattr -dr com.apple.quarantine /Applications/RunHam.app` in Terminal.

## 설치 / 업데이트

**macOS 14 이상, Apple 실리콘(M1 이후) Mac이 필요합니다.**

1. RunHam이 실행 중이면 종료합니다. 설정, 러너, 메트릭은 그대로 남습니다.
2. 아래 `RunHam-0.1.1.zip`을 받아 압축을 풀고 `RunHam.app`을 응용 프로그램 폴더로 옮깁니다(기존 앱을 대치).
3. 아직 Apple 공증을 받지 않아 처음 실행이 막힙니다. 아래 중 한 가지로 한 번 열어 주세요.
   - `RunHam.app`을 우클릭(Control-클릭)하고 **열기**를 누른 뒤 다시 **열기**를 누릅니다.
   - 또는 한 번 실행해 본 뒤 **시스템 설정 › 개인정보 보호 및 보안**에서 **그래도 열기**를 누릅니다.
   - 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/RunHam.app`을 실행합니다.
